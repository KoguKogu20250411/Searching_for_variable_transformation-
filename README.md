# SymbolicRegression Transformation Searcher

このプロジェクトは、Juliaの強力な数式探索パッケージである `SymbolicRegression.jl` を活用し、**複雑な数式をよりシンプルな形（標準形など）に変換するための「変数変換則」を自動探索**するスクリプトです。

物理学におけるラグランジアンの座標変換や、多変数関数の平方完成のようなタスクを、機械学習的アプローチ（遺伝的アルゴリズム）で解くことを目的としています。

## 主な機能

本スクリプトは大きく分けて2つの探索タスクをサポートしています。

### 1. 多変数・交互最適化タスク (Coordinate Descent)
複数の入力変数を持つ複雑な数式（LHS）を、よりシンプルな数式（RHS）にマッピングするための新しい変数（u, v, ...）を探索します。
探索には**交互最適化（Coordinate Descent）**の手法を用いており、一方の変数を固定して他方を最適化するプロセスを指定のラウンド数繰り返します。

**テスト実装例（平方完成）:**
* **変換前 (LHS):** 0.5(x^2 + 2x + y^2 + 4y + 5)
* **変換後 (RHS):** 0.5(u^2 + v^2)
* **期待される発見:** u = x + 1, v = y + 2 などの平行移動変換。

### 2. ラグランジアン変換タスク (連鎖律 / Chain Rule)
物理系のラグランジアンにおいて、座標 x と速度 v（または dx/dt）からなる複雑な系を、別のシンプルな系のラグランジアンに変換するための座標変換 u(x) を探索します。
内部で**微分の連鎖律（チェーンルール）**を数値的に処理し、du/dt = (du/dx) * v を計算して損失関数に組み込んでいます。

**テスト実装例（ずれた調和振動子）:**
* **変換前 (LHS):** 0.5v^2 - 0.5(x - 3)^2
* **変換後 (RHS):** 0.5(du/dt)^2 - 0.5u^2
* **期待される発見:** u = x - 3

## 必要要件 (Prerequisites)

このスクリプトを実行するには、Julia環境と以下のパッケージが必要です。

* Julia (v1.6以上を推奨)
* [SymbolicRegression.jl](https://github.com/MilesCranmer/SymbolicRegression.jl)

パッケージのインストールは、JuliaのREPLから以下のコマンドを実行してください。

```julia
using Pkg
Pkg.add("SymbolicRegression")
```

## コードの構成

* `0. 共通ユーティリティ・基底関数`:
    数式探索で使用する演算子（`sq`, `safe_sqrt`など）や、Hall of Fame (HoF) から最も損失の低い最良の木（数式）を抽出するヘルパー関数を定義しています。
* `1. 【多変数 ↔ 多変数】 交互最適化タスク`:
    多変数関数の変換則を探索するための構造体 `MultiTransformationTask` と、交互に最適化を行う実行関数 `run_multi_transformation_search` が含まれます。カスタム損失関数により定数項のズレ（C）を吸収する仕組みが入っています。
* `2. 【ラグランジアン】 連鎖律（チェーンルール）タスク`:
    位置と速度の依存関係を考慮した変換タスク用の構造体 `LagrangianTask` と、数値微分を用いて連鎖律を適用するカスタム損失関数が含まれています。
* `3. 実行・テストブロック`:
    スクリプトの末尾にある実行ブロックです。デフォルトでは多変数タスク（テストA）が実行されるように設定されています。テストBを実行したい場合はコメントアウトを外してください。

## 実行方法

ターミナルまたはコマンドプロンプトから、直接スクリプトを実行します。

```bash
julia main.jl
```

実行すると、標準出力に探索の進捗状況（各ラウンドごとの Hall of Fame の更新状態）が表示され、最終的に発見された数式が出力されます。

## パラメータの調整

探索がうまくいかない場合や、より複雑な式を探索したい場合は、実行関数を呼び出す際の引数を調整してください。

* `N`: 訓練用のランダムサンプリング数（デフォルト: 200）
* `niterations`: `EquationSearch` のイテレーション数。増やすと探索時間が伸びますが、より複雑な解を見つけやすくなります。
* `max_rounds` (多変数用): 変数を交互に最適化する往復の回数（デフォルト: 2）
* `early_stop_condition`: 指定した損失値（例: `1e-10`）や式の複雑さ（complexity）を下回った場合に探索を早期終了します。式が複雑になりすぎる場合はこの条件を調整してください。
